```text
verification_agent 能稳定识别失败并生成 repair_plan。
```

## 5. 本轮关键升级

| 升级点 | 结果 |
|---|---|
| 参数级修正验证 | 从简单关键词匹配升级为按 `failure_type` 判断修正动作 |
| `missing_sandbox_file` | 沙盒源文件缺失时允许先定位真实沙盒产物 |
| `missing_vector_artifact` | GeoJSON 发布 / 可视化路径缺失时允许先定位同类矢量产物 |
| Shapefile 缺组件 | 允许重导工具隐式生成 `.shp/.dbf/.shx`, 不强制参数文本包含扩展名 |
| 证据不足 | 允许 shell / python 检查报告、路径、PDF、产物证据 |
| 建筑物参数修正 | 允许“建筑 / 建筑物 / building / 房屋”等同类语义归一 |

## 6. 当前判断

当前阶段已经达到 80 分通过线以上, 并在固定 10 条真实行为评估集上达到 100 分。

下一阶段不应继续主要优化 prompt, 而应转向:

```text
把 decision_audit 接入长期运行分析。
建立 repair_success_rate, 观察修正动作之后工具是否真的通过。
把高价值失败沉淀为结构化反思记忆和技能规范。
为遥感、发布、报告 worker 增加独立汇报协议和工具权限边界。
```
