> 用途：给「国土智察」工作台/管理端的视觉与信息架构找参照，降低通用 AI SaaS 观感。
> **最新基线（阶段 31）**：整体视觉改为参考 **DeepSeek 桌面客户端**——近白底、浅灰侧栏、

## 二、这类系统的共性（从参考里提炼）

1. **顶部一条指标带**：国土面积、耕地、永久基本农田、生态红线、建设用地、矿山、保护地、预警数……
   指标横排、等宽、带单位（万公顷 / ha / 件 / %），点击可下钻。
2. **地图是主角**：占页面 60% 以上；左右两侧是专题面板；图层开关、图例、测量、查询直接叠在地图上。
3. **深色“驾驶舱”**：`#0a1f33` 底 + 青色细描边 + 金色数值，适合大屏汇报与值守，不适合长时间读文本。
4. **信息密度高**：正文 11–12px，行高紧凑；表格/列表优先于大卡片；几乎没有大片留白。
5. **机构化顶栏**：系统全称、日期时间、天气、区域选择、账号/角色；底部常有预警滚动条。
6. **颜色语义固定**：耕地绿、建设用地黄、生态红线红、水域蓝；状态色（正常/预警/超期）贯穿图表与列表。
7. **入口是“专题/业务模块”**：不是聊天欢迎语；任务以待办列表、处置状态、进度条推进。
8. **字体**：微软雅黑 / 思源黑体一类的无衬线中文，数字用等宽或半等宽，单位不省略。

## 三、我们采用的（已在阶段 29 落地）

| 采用点 | 落地位置 |
|---|---|
| 机构式顶栏：只保留「国土智察 自然资源遥感智能监测系统」一行，去掉英文副题与灰色小标签；右侧链路状态 + 时间 + 账号 | `MainLayout.vue` |
| 左栏改为“新建解译任务”主按钮 + 搜索/图层/技能/MCP 工具条 | `ConvSidebar.vue` |
| 右栏去掉“AI 助手欢迎语”和任务选项，只留**居中的欢迎提示** | `ChatPanel.vue` |
| 方形标识块、细边框、小圆角，去掉悬浮阴影与胶囊按钮 | `theme.css` + 各组件 |
| 小字号、紧凑行高、数字等宽；表格/列表优先 | `shell.css` + 组件样式 |
| 字体统一 **微软雅黑**（含 Element Plus） | `theme.css` |

**明确不采用**：深色大屏驾驶舱。它是汇报/值守场景，日常办公+对话阅读在浅色下更稳；
如果以后要做“领导驾驶舱”，建议单独开一个只读大屏页，而不是改工作台。

## 四、为什么之前“AI 味”重（问题清单）

| 观感来源 | 处理 |
|---|---|
| 圆形机器人头像 + “我是 AI 助手”欢迎语 | 换成方形“智”标识 + 居中欢迎提示 |
| 胶囊形快捷问题、蓝色渐变、宽留白 | 去掉快捷选项，改成居中文案 |
| 悬浮阴影、8px 大圆角、按钮上浮微交互 | 统一 1–3px 小圆角、去阴影、去位移 |
| 顶部白色 SaaS 风导航 + 绿色在线点 | 机构式标识栏：系统全称一行 + 链路/时间/账号 |
| 左侧五条菜单式入口 | 主按钮 + 工具条 + 「项目空间 / 会话记录」分区 |

## 五、后续可继续做的（未在本轮）

1. 管理端 KPI 从独立卡片改成一条**指标带**（竖线分隔、可下钻）。
2. 工作台底部增加**状态条**：当前项目、坐标系、图层数、最近任务、链路时延。
3. 地图图例、图层树按“业务分类”分组（基础现状 / 规划管控 / 专题应用）。
4. 引入业务状态色板（耕地/建设/红线/水域），统一图表与列表语义。
5. 若做大屏：单独 `/screen` 路由 + 深色主题，与工作台隔离。
