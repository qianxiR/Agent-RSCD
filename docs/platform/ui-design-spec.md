# 非 Agent 核心 UI 设计规范（V1 草案）

> 目标：先做出“没有 Agent 也能用”的遥感数据与解译平台 UI；Agent 后续作为右下角 Copilot 接入，而不是占据主界面。
>
> 配套架构：[core-architecture-design.md](./core-architecture-design.md)
> 生产级双门户（用户端 + 管理端）：[production-architecture.md](./production-architecture.md) · [two-portal-ui-design.md](./two-portal-ui-design.md)
> 静态原型：`docs/platform/core-ui-mockup.html` · `docs/platform/admin-ui-mockup.html`

---

## 一、设计判断

### 1.1 当前 UI 的问题

当前是“聊天工作台”：

```text
┌────────────┬──────────────────────────┬──────────────┐
│ 对话/图层   │        地图              │    聊天       │
│ 技能/MCP    │                          │  输入/结果    │
└────────────┴──────────────────────────┴──────────────┘
```

问题不是视觉，而是**信息架构**：

- 项目只是对话分组，没有项目主页；
- 数据入口是“图层”而非“数据集”，上传是聊天附件；
- 任务只是聊天里的进度条，没有任务中心；
- 结果只存在于会话消息，关闭会话就找不到；
- 聊天占据 420px 固定宽度，挤占地图；
- 没有路由，无法分享/刷新到某个项目、任务、结果。

### 1.2 目标信息架构

```text
项目（上下文）
├── 项目总览        /projects/:projectId
├── 数据中心        /projects/:projectId/datasets
│   ├── 影像
│   ├── 矢量
│   └── 文档/表格
├── 地图工作台      /projects/:projectId/map
├── 分析任务        /projects/:projectId/jobs
│   ├── 新建任务
│   └── 任务详情
├── 结果中心        /projects/:projectId/results
├── 报告中心        /projects/:projectId/reports
└── 项目设置        /projects/:projectId/settings
```

全局：

```text
/                    项目列表 / 最近项目
/login               登录
/settings            个人设置（模型/偏好）
```

Agent 后续：

```text
任意页面右下角 [Copilot] → 抽屉，携带当前项目/数据集/任务上下文
```

## 二、布局规范

### 2.1 App Shell

```text
┌─────────────────────────────────────────────────────────────────────┐
│ TopBar 56px: Logo | 项目切换 | 全局搜索 | 任务中心 | 用户              │
├──────┬──────────────────────────────────────────────────────────────┤
│ Nav  │ Page Header (标题/面包屑/主操作)                              │
│ 64px ├──────────────────────────────────────────────────────────────┤
│      │                                                              │
│ 项目 │                     Page Content                             │
│ 数据 │                                                              │
│ 地图 │                                                              │
│ 任务 │                                                              │
│ 结果 │                                                              │
│ 报告 │                                                              │
│      │                                                              │
│ 设置 │                                                              │
└──────┴──────────────────────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 说明 |
|---|---|---|
| TopBar | 56px | 品牌、项目切换、搜索、任务铃、用户 |
| Nav Rail | 64px | 图标 + 文字，当前页高亮；可折叠为 48px |
| Page Header | 56–72px | 标题、面包屑、主操作（上传/新建任务） |
| Content | flex | 表格/卡片/地图 |
| Inspector | 320–360px | 详情面板，按页面出现，可收起 |
| Copilot | 380–420px | 右侧抽屉，默认关闭 |

### 2.2 页面级布局

| 页面 | 布局 |
|---|---|
| 项目总览 | 12 栅格：KPI 4 卡 + 最近任务 + 项目资产 + 快捷入口 |
| 数据中心 | 左筛选/分类 240px + 主表格 + 右侧详情 Inspector |
| 地图工作台 | 左图层树 280px + 地图 flex + 右属性/图例 320px |
| 任务中心 | 任务列表（左 55%）+ 任务详情/日志（右 45%） |
| 结果中心 | 结果卡片瀑布/表格 + 预览抽屉 |
| 报告中心 | 模板卡片 + 报告列表 + 预览 |

## 三、视觉语言

### 3.1 设计令牌（沿用现有主题，增强层级）

当前 `theme.css` 已有蓝/白/灰体系，可以直接扩展：

| 令牌 | 建议值 | 用途 |
|---|---|---|
| `--bg-base` | `#f5f6f8` | 页面底色 |
| `--bg-panel` | `#ffffff` | 卡片/面板 |
| `--border` | `#e4e7ec` | 分隔线 |
| `--accent` | `#2c6fbd` | 主操作/选中 |
| `--text-primary` | `#1e2d3a` | 主文字 |
| `--text-secondary` | `#5a7488` | 次级文字 |
| `--ok` / `--warn` / `--danger` | `#3fae5a` / `#d68910` / `#cf4444` | 状态 |
| 圆角 | 6/8/10px | 卡片/面板 |
| 间距 | 4/8/12/16/24 | 统一节奏 |

**字号调整**：当前全站 10–16px 偏小。数据平台建议：

- 页面标题 20px / 600
- 区块标题 14px / 600
- 正文/表格 13px
- 辅助文字 12px
- 数字/KPI 28px / 700

### 3.2 关键组件

- **Project Switcher**：顶部左侧，显示当前项目 + 下拉切换/新建。
- **KPI Card**：数字 + 环比/说明 + 图标，4 个一排。
- **Dataset Table**：缩略图、名称、类型、CRS、范围、大小、来源、状态、操作。
- **Layer Tree**：项目图层分组（影像/矢量/分析结果）+ 显隐 + 定位 + 样式。
- **Job Card/Row**：类型图标、输入、状态、进度、耗时、操作（查看/取消/重试）。
- **Artifact Card**：缩略图、类型、来源任务、时间、下载/发布/报告。
- **Inspector**：属性键值、CRS/bbox、血缘、操作按钮。
- **Empty State**：一句话说明 + 一个主操作，不堆插画。
- **Copilot Drawer**：上下文 chips（项目/数据集/任务）+ 对话 + 建议操作。

## 四、页面设计

### 4.1 项目总览

**目标**：打开就知道这个项目有什么、最近发生了什么、下一步做什么。

```text
项目：成都市变化监测                      [上传数据] [新建分析]
────────────────────────────────────────────────────────────
[数据集 12] [图层 8] [运行中任务 2] [产物 36]

最近任务
┌──────────────────────────────────────────────────────────┐
│ 变化检测 · T1/T2 · 运行中 62% · 2 分钟前        [查看]    │
│ 分割 · 2026-10 影像 · 完成 · 12 秒前            [结果]    │
└──────────────────────────────────────────────────────────┘

项目资产
[影像缩略图] [矢量预览] [报告封面]  → 查看全部

快捷操作
[上传影像] [打开地图] [新建变化检测] [生成报告]
```

### 4.2 数据中心

**目标**：项目所有输入资产可管理、可预览、可发布。

```text
数据中心                    [上传] [从 GeoServer 导入]
[全部 12] [影像 8] [矢量 3] [文档 1]       搜索…
┌────┬──────────────┬──────┬────────┬──────────┬────────┬──────┐
│ □  │ 名称          │ 类型 │ CRS    │ 范围      │ 状态   │ 操作 │
├────┼──────────────┼──────┼────────┼──────────┼────────┼──────┤
│ □  │ 2026-10 影像  │ 栅格 │ 4490   │ 103.9…   │ 就绪   │ …    │
│ □  │ 变化图斑      │ 矢量 │ 4490   │ 103.9…   │ 已发布 │ …    │
└────┴──────────────┴──────┴────────┴──────────┴────────┴──────┘
右侧 Inspector：缩略图 + 元数据 + 预览 + 发布/删除
```

交互：

- 拖拽上传 → 上传队列（进度/失败重试）；
- 上传完成自动解析 CRS/bbox/缩略图；
- 行点击打开 Inspector，不跳页；
- 多选 → 批量删除/批量发布/批量分析；
- 无 CRS 影像明确提示“不可用于分析”。

### 4.3 地图工作台

**目标**：项目数据的空间工作区，不依赖聊天。

```text
┌──────────────┬──────────────────────────────────┬──────────────┐
│ 图层          │                                  │ 属性/图例     │
│ 底图          │            地图                   │ 图层：变化图斑 │
│ 项目图层      │                                  │ CRS/范围      │
│  影像         │                                  │ 类别图例      │
│  矢量         │                                  │ 操作：定位/透明度│
│  分析结果     │                                  │              │
└──────────────┴──────────────────────────────────┴──────────────┘
```

功能：

- 图层树按项目资产分组，不直接暴露 GeoServer 工作空间；
- 显隐/透明度/定位/样式；定位按图层外接矩形自适应缩放（小图斑最高 20 级），并留 56px 边距；
- 点击要素 → Inspector 属性；
- 框选/绘制选区 → “对选区分析”（创建 job，params 带 bbox/geometry）；
- 底部状态栏：坐标、比例尺、当前 CRS；
- 地图功能入口统一在**左上角工具条**，从左到右追加：`图层` → `卷帘` → `地物提取` → `变化检测` → 后续新增项；右上角只保留缩放；
- 双时相卷帘已接入：Esri Wayback 年度版本，左右拖动分隔线对比；
- 变化检测：区域选择 → 选择 T1/T2 两个 Esri Wayback 版本 → 两期高清影像进入聊天附件 → `detect_change`。

### 4.4 分析任务

**目标**：人工可以完成“选数据 → 配参数 → 跑任务 → 看结果”。

新建任务向导（右侧抽屉或独立页）：

```text
1 选择类型   [语义分割] [变化检测] [预处理] [发布图层]
2 选择输入   数据集多选（按类型过滤）
3 参数       类别、阈值、滑窗、输出格式
4 确认       预计耗时/显存提示 → [开始任务]
```

任务列表：

```text
任务中心                     [新建任务]
[全部] [运行中] [完成] [失败]
┌──────────────────────────────────────────────────────────┐
│ 变化检测 · T1/T2 · 运行中 62% · 01:23 · [取消] [日志]     │
│ 语义分割 · 影像A · 完成 · 19s · [结果] [发布] [报告]      │
└──────────────────────────────────────────────────────────┘
```

右侧详情：阶段、进度、日志、输入/输出、错误建议、产物。

### 4.5 结果中心

**目标**：产物是资产，不是聊天记录。

- 卡片/表格两种视图；
- 类型：分割掩膜、变化掩膜、矢量图斑、统计表、报告；
- 预览：PNG 大图、GeoJSON 地图预览、表格；
- 操作：下载、发布为图层、生成报告、加入对比；
- 双时相对比：T1/T2/变化掩膜三视图 + 滑动对比（后续）。

### 4.6 报告中心

- 模板卡片：监测报告/变化分析/自定义；
- 选择项目/任务/产物 → 生成；
- 列表：状态、版本、生成时间、下载/预览；
- 报告详情：章节、图表、引用产物。

### 4.7 设置

- 项目设置：名称/描述/标签/归档/成员（后续）；
- 数据设置：默认 CRS、存储路径、GeoServer 工作空间；
- 模型设置：分割/变化检测默认参数（阈值、滑窗、类别）；
- 系统设置：任务并发、日志保留、通知。

## 五、Agent Copilot 的 UI 形态（后续）

不要把聊天做成第三栏。建议：

```text
右下角悬浮按钮  [✦ Copilot]
点击 → 右侧抽屉 380px：
┌──────────────────────────────┐
│ Copilot        [项目上下文]   │
│ 当前：成都市变化监测 / 影像A  │
│ ┌──────────────────────────┐ │
│ │ 建议：对影像A做建筑分割   │ │
│ └──────────────────────────┘ │
│ 对话…                        │
│ [输入框]                     │
└──────────────────────────────┘
```

规则：

- 默认关闭，不挤占地图；
- 打开时地图自动让出 380px，可拖拽；
- 上下文 chips 可移除/切换；
- Agent 只能发“建议/命令”，执行仍走 Job API；
- 危险操作（删除/覆盖/发布）必须二次确认；
- Agent 生成的任务在任务中心与人工任务同列，标 `source=agent`。

## 六、交互与状态

### 6.1 关键流程

**上传 → 入库**

1. 点击上传/拖拽；
2. 上传队列显示进度；
3. 解析中 → 就绪/失败；
4. 成功后自动出现在表格，Inspector 可预览；
5. 失败给出原因（无 CRS/格式不支持/超大）。

**新建分析**

1. 从项目总览/数据中心/地图选区进入；
2. 向导预填输入；
3. 创建后 202 + job_id；
4. 任务中心出现，SSE/轮询更新；
5. 完成后结果中心出现产物，可发布/报告。

### 6.2 状态设计

| 状态 | 表现 |
|---|---|
| 空 | 一句话 + 主操作（上传/新建） |
| 加载 | 骨架屏，不用全屏 spinner |
| 错误 | 行内错误 + 重试；不弹大模态 |
| 权限不足 | 禁用操作 + tooltip 说明 |
| 长任务 | 进度条 + 阶段 + 可离开页面 |
| 断线 | 顶部条“实时连接断开，已切换轮询” |

### 6.3 键盘/可访问性

- `Ctrl/Cmd + K` 全局搜索；
- `G then P/D/M/J/R` 快速切页（可选）；
- 所有图标按钮有 `aria-label`；
- 表格支持键盘行导航；
- 颜色不作为唯一状态标识（配文字/图标）。

## 七、响应式

| 宽度 | 行为 |
|---|---|
| ≥1440 | 三栏（Nav + Content + Inspector） |
| 1024–1440 | Inspector 可收起；Nav 图标化 |

移动端不是一期目标，但至少保证“项目列表/任务状态/结果下载”可读。

## 九、验收标准（UI 一期）

- [ ] 不打开聊天，能从项目列表进入项目并看到 KPI/最近任务；
- [ ] 能上传一个 GeoTIFF，看到解析后的 CRS/bbox/缩略图；
- [ ] 能在地图工作台把项目图层叠加显示/隐藏/定位；
- [ ] 能新建一次分割任务，看到进度和完成状态；
- [ ] 能在结果中心找到产物并下载；
- [ ] 刷新/分享 URL 能回到同一项目/任务/结果；
- [ ] Agent 抽屉关闭时，所有上述流程不受影响。
