# 《企业高质量数据集与大模型/智能体应用闭环》课程大纲

## 一、课程总纲

**核心主线：**  
建（盘点）→ 存（治理）→ 用（结合大模型）→ 验（对齐）

**核心公式：**  
高质量数据集 = 数据 × 质量 × 结构 × 标签 × 对齐  
五要素缺一不可。

**核心目标：**  
让企业数据“被大模型/智能体可靠调用”，而不只是“存起来”。

**四章对应关系：**

- 第一章：建（盘点）——高质量数据集建设
- 第二章：存（治理）——存储设计与数据治理
- 第三章：用（结合大模型）——知识增强与智能应用
- 第四章：验（对齐）——数据对齐与闭环验证

---

# 第一章 建（盘点）：高质量数据集建设

## 1.1 高质量数据集基本概念、体系和框架

- 高质量数据集的定义、价值与评价标准
- 高质量数据集五要素：数据、质量、结构、标签、对齐
- 数据资产盘点、数据目录、来源梳理、权属与合规
- 数据集建设体系：标准、流程、角色、工具、评估机制

## 1.2 数据的类型及采集方式

- 数据类型：结构化、半结构化、非结构化
- 常见形态：文本、图片、文档、表格、日志、时序、交通数据等
- 采集方式：业务系统、API、埋点、传感器、公开数据、人工录入、文档解析

## 1.3 数据质量和数据清洗

- 数据质量维度：完整性、准确性、一致性、及时性、唯一性、有效性
- 常见问题：缺失、重复、异常、噪声、格式不统一
- 数据清洗：去重、补全、纠错、标准化、脱敏、归一化

## 1.4 数据加工和标注

- 数据加工：清洗、转换、切片、增强、脱敏、版本管理
- 数据标注：分类、实体、关系、问答、偏好、多模态标注
- 标注规范、标注质检、一致性评估

## 实践操作：数据自动化标注

- 规则预标注、模型预标注、人机协同标注
- 标注结果质检与修正
- 产出：高质量数据集雏形、标注规范、数据卡

## 2.3 不同存储模型的计算方法和应用案例

- 不同存储模型选型对比
- 应用案例：智能问数、知识检索、关系分析、语义搜索

## 实践操作：数据的向量化表示与向量数据库调用

- 文本切片、向量化、入库、检索、过滤、重排

# 二、课程闭环与五要素映射

| 闭环阶段         | 核心任务                            | 对应五要素       |
| ---------------- | ----------------------------------- | ---------------- |
| 建（盘点）       | 数据盘点、采集、清洗、标注          | 数据、质量、标签 |
| 存（治理）       | 存储设计、索引、向量化、图谱化      | 结构             |
| 用（结合大模型） | 微调、RAG、提示词、智能体、智能问答 | 调用与落地       |
| 验（对齐）       | 数据对齐、效果评估、风险控制        | 对齐             |

**最终形成闭环：**  
盘点建设 → 治理存储 → 大模型/智能体调用 → 对齐验证 → 反馈优化 → 再回到建设与治理。
