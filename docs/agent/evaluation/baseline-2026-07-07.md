## 8. 当前评估边界

In scope:

- `verification_agent` 的基础状态判断。
- `repair_policy` 的失败归因和修正策略生成。
- ToolMessage 的 `agent_validation` / `repair_plan` 回灌。
- prompt 构建器能输出基础 system prompt blocks, 且关键修正规则未被误删。
- 真实 LLM 在固定失败上下文中的下一步动作观测。

Out of scope:

- 多轮真实对话中的重复失败率。
- 长期记忆是否正确沉淀 lesson。
- skill 是否被正确选择和执行。
- 遥感 / 发布 / 报告 worker 的专业任务完成质量。
