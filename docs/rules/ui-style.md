# Agent-RSCD 用户端 UI 规则

> 适用范围：`frontend-vue/` 用户端（工作台 `/`、地图面板、会话面板、业务弹窗）。
> 令牌来源：`frontend-vue/src/styles/theme.css`。
> 不在范围：管理端 `/admin/**` 的 `shell.css` 体系。

## 一、令牌

| 类别 | 取值 |
|---|---|
| 字号 | 12 / 13 / 16 / 20px 四级；正文 13px |
| 字重 | 400 / 500 / 600 |
| 圆角 | `--r-xs` 4 / `--r-sm` 6 / `--r-md` 8 / `--r-lg` 10 / `--r-shell` 12 |
| 背景 | 基底 `#f5f5f3`、面板 `#fcfcfb`、悬停 `#efefec`、内嵌 `#f0f0ed`、下沉 `#ecece8` |
| 文字 | 主 `#1a1a18`、次 `#5f5f59`、弱 `#8d8d86` |
| 边框 | `rgba(24,24,20,.07)` / `.12` / `.04`，线宽 0.5px |
| 品牌色 | 低饱和靛蓝 `#4b5fd6`，仅品牌标识与少量装饰 |
| 阴影 | 不用纯黑；`--shadow-shell` / `--shadow-soft` / `--shadow-float` |
| 动效 | 120 / 180 / 260ms 三档 |

## 二、字体

```css
font-family: "Times New Roman", SimSun, serif;
```

- 普通文字：英文与数字用 Times New Roman，中文回退宋体。
- 代码、日志、坐标等需要等宽对齐的内容保持 `--mono`，不套用此规则。
- 通过全局变量 `--sans`、`--el-font-family` 统一生效，不在组件内散落硬编码。

## 三、层级

- 文字三级灰阶：primary / secondary / muted；层级靠字号与字重区分，禁止全站统一单色。
- 背景层级靠 1%–3% 明度差区分，不靠深色线条。
- 分隔优先用发丝级半透明边框，不用深色实线。
- 界面不出现浅蓝色高亮。

## 四、状态

- 聚焦态与基态一致：无描边、无发光、无背景切换。
- 悬停态用更浅的中性灰。
- 选中/激活态用 `#ececec` 中性灰底 + 正常文字色；禁止彩色底（如浅蓝底 + 蓝字）。
- 表单控件（复选框、单选、滑块）用近黑 `#1a1a18`。
- 颜色传达语义，不做装饰。

## 五、按钮

- 主按钮：每屏唯一的检索/发送/执行类 CTA，黑色 `#1a1a1a` 底白字，hover `#111110`。
- 次按钮：`--bg-inset` 底 + `--text-secondary` 文字。
- 图标按钮：透明底，hover 中性灰。
- 按钮不用彩色底。

## 六、形态与动效

- 同心圆角：外大内小。
- 阴影不用纯黑。
- 动效克制，120 / 180 / 260ms 三档，禁止 bounce。
- 弹窗与侧栏面板复用既有外壳结构，不引入第二套卡片/按钮风格。

## 七、地图工具条与浮层

- 工具条统一在左上角，横排，`height: 28px`，白底、发丝边框、`--r-sm` 圆角、`--shadow-shell`。
- 浮层从工具条下方展开，宽 300–340px，白底 `--r-md` 圆角 `--shadow-float`。
- 工具条按钮选中态用中性灰底 + 主文字色，不使用强调色描边或彩色底。
- 地图上的要素颜色只用于编码业务类别；选中要素用加粗描边 + 白色外圈表达，不用强调色。
- 浮层与面板共用一套头部结构：标题 + 关闭图标按钮。

## 八、十条设计规则

1. 去边框：靠 1%–3% 微明度分层，禁纯黑 `#000`；文字用近黑 `#1a1a18`。
2. 输入框：聚焦不加 outline，加深双环 box-shadow 造咬合感。
3. 暗色补偿：字重全降 40（如 400→360），防白字发胖。
4. 流式打字：单字 90ms 从 `blur(6px)` 到清晰，缓动 `cubic-bezier(.215,.61,.355,1)`，相邻字错开 30ms。
5. 行内图标：`vertical-align: -0.125em` 对齐中心。
6. 数字防抖：加 `tabular-nums` 锁等宽。
7. 丝滑折叠：免 JS 算高，用 Grid `0fr → 1fr` 过渡。
8. 防孤字：正文加 `text-wrap: pretty`。
9. 动效性格：拖拽用过阻尼弹簧（1200/80）零回弹；点赞/对勾用欠阻尼（380/18）微弹。
10. 反馈自熄：复制对勾 2.5s 后自动淡出恢复。

## 九、禁止项

- 浅蓝色高亮、彩色选中底、强调色描边表示选中。
- 纯黑文字或纯黑阴影。
- 卡片套卡片。
- 紫色渐变作为默认配色。
- bounce / elastic 缓动。
- 在业务组件内硬编码字体族与颜色，绕过 `theme.css` 令牌。
